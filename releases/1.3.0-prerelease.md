## 1.3.0 prerelease

Testing build for World of Tanks EU 2.4.1.1. Download the complete ZIP again if you already installed 1.3.0 and run the in-game checks against this package.

### What to test

- **Garage tracking.** Check quests, challenges and all three tournament categories in the garage card and detailed window. Navigate the grouped selector with the keyboard and mouse wheel, including in the shared garage column. Compare official scores, standings and battle counts with the website, follow an event through qualification and bracket rounds including third place, and check that restricted map defender scores stay hidden.
- **Recent results.** Check that resolved quests and closed challenges disappear after 24 hours and settled tournament participations after one hour. Verify that cancellations and withdrawals disappear and that expiration preserves the saved selection on the website. With the selector open, check that focus returns to its button if the focused objective expires.
- **Pending battle progress.** Play two eligible battles and check that both views show the cumulative delta next to the published score until the battles are counted. Check negative deltas and the **Calculation pending** label when the exact delta depends on a later Wargaming update. Switch objectives and accounts, and test returning from battle and reconnecting.
- **Battle reporting.** For supported single-vehicle Random battles, compare base, premium-applied and initial-total combat XP, Free XP and credits with the battle results. Check that clan credit bonuses affect totals and leave bonus-free bases intact, and that real credit expenses can produce a negative net amount. Unmapped special modes continue to report as **Other**. The build records the client's battle type names to help identify new event modes.

### Installation

1. Use a Battle-Conquest server with the matching [tournament tracking](https://github.com/Battle-Conquest/Battle-Conquest/pull/1127), [economy scoring](https://github.com/Battle-Conquest/Battle-Conquest/issues/1143), [recent results](https://github.com/Battle-Conquest/Battle-Conquest/pull/1153) and [pending progress](https://github.com/Battle-Conquest/Battle-Conquest/pull/1154) changes deployed.
2. Close the game, preserve `mods/configs/battle_conquest/`, remove the previous package and disable any development bootstrap.
3. Extract `battle-conquest-mod_1.3.0.zip` into the game directory. Keep one Battle-Conquest package and one OpenWG Gameface 1.2.2 package in the shared `mods/2.4.1.1/net.openwg/` folder. The standalone `.wotmod` uses the detailed window if Gameface is absent.
4. Restart the game and verify that the account is linked before starting the checks.
